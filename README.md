Python code supporting the empirical analysis of my Master's thesis on the geographical distribution and regional specialisation of Enterprise AI innovation in the Netherlands.

# Enterprise AI Innovation in the Netherlands

This repository contains the Python code used for the empirical analysis
conducted as part of my Master's thesis.

## Research Question

How do the geographical distributions of Enterprise AI patents and startups
compare across the Netherlands, and what do these patterns reveal about
regional specialisation?

## Analysis

The repository contains code for:

- Data cleaning and preparation
- Temporal analysis (2015–2025)
- NUTS 2 geographical analysis
- NUTS 3 / COROP geographical analysis
- Location Quotient (LQ) analysis
- CPC technological classification
- Regional technological profiles
- Patent–startup regional orientation

## Data

The empirical analysis uses two datasets:

- 167 validated Enterprise AI patents
- 91 Enterprise AI startups

The underlying datasets are not included in this repository.

## Geographical Classification

Regional analyses are conducted at:

- NUTS 2 level
- NUTS 3 / COROP level

Geographical boundaries are based on Eurostat NUTS classifications.

## Software

The analysis was conducted in Python using packages including:

- pandas
- geopandas
- matplotlib
- openpyxl
- pyogrio
